# FoilStep Lab V1.9.4

Офлайн приложение за геометрична оптимизация на подаване на фолио, ръчни схеми и запазване на настройки.

**Android:** след активиране на GitHub Pages отвори https://kamentuplovdiv-stack.github.io/foilstep-lab/ в Chrome → меню ⋮ → „Инсталирай приложение“ или „Добавяне към началния екран“.

**Запазени настройки:** „Моите настройки“ → име → „Запази“; за прехвърляне и резервно копие използвай JSON. Данните се пазят само локално на устройството; изчистване на данните на сайта ги изтрива.

**Ограничения:** геометричен тестов модел, не е официален OACS на BOBST и не управлява машината. Сверявай работните схеми с реалното производство. Кодът в GitHub е публичен, затова не качвай клиентски производствени рецепти в репозитория.
