# FoilStep Lab V1.9.15

Самостоятелно приложение за геометричен анализ на подаването на фолио. Съдържа 10 базови автоматични + №11 ръчен + №12 вложен N цикъл.

**Отваряне на Android в Chrome:** https://kamentuplovdiv-stack.github.io/foilstep-lab/ . Актуализацията на уеб версията не изисква APK.

## Поправки V1.9.15

- Премахнат е двустъпковият диагностичен панел, който обърква сравнението.
- Отстранен е дефект при минимална междина 0 mm: двойки, които са разделени по Y, не бива да забраняват X движенията.
- №12 търси A/B на адаптивна решетка по допустимите геометрични интервали за всяко N от 1 до 25; C се определя аналитично и се проверява повторението на периода.
- №12 остава винаги видим, включително когато няма допустим кандидат.
- Има два явно отделени режима: **зададен минимум + резерв за грешка** и **диагностика с 0 mm**, която **не е потвърдена машинна настройка**.
- Панелът за ръчна проверка вече допуска въвеждане само на схема А или схема Б; показва цялата последователност, средното подаване и реалната моделирана междина.

### Ограничения

Нулевата междина допуска допиране на отпечатъци, не включва динамичните отклонения, а механичните ограничения за изчистване и реалната OACS логика трябва да бъдат проверени отделно. Алгоритъмът е ограничено числено/евристично търсене и **не доказва глобален оптимум**. Y-застъпванията без реални Y координати дават условни резултати.

### Резервни копия

Преди да смениш Android инсталацията, експортирай настройките и проектите като JSON. Android APK от различни GitHub Actions компилации може да е подписан с различни debug ключове. За сигурно приложение с обновяване използвай уеб/PWA версията; не деинсталирай старото APK преди архив.
